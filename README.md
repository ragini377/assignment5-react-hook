In this project:-

A custom hook named useFetch is created.

The hook accepts a URL parameter.

It fetches data from an API using the useEffect() function.

It handles -:

 1 Loading state

 2 Error state

3 Data state

A simple React component displays the fetched data.

Tech Used -:

1. React (Vite)

2.JavaScript (ES6)

3.Tailwind css
